Strava Support & Data Help

Help for Savills employees using the Strava integration in Run for Impact 2026.

Connect Strava

  1. Sign in to your approved Run for Impact account.
  2. Select Connect with Strava.
  3. Review the permissions shown by Strava and authorize the connection.
  4. Return to Run for Impact. Your eligible activity data can then be used for your personal campaign experience.

Privacy: Strava data received for a specific authenticated user is displayed only to that user in the Savills application.

Disconnect Strava

You can revoke Run for Impact's access from your Strava account at any time.

Open Strava app settings

After revoking access, the application will no longer be able to retrieve new Strava data for your account.

Your data & deletion requests

You may request access to the Strava data collected for your account, or request deletion of Strava-derived data held by Run for Impact. You may also withdraw access by disconnecting the application in Strava.

For a deletion request, contact the Run for Impact organizing team using the support contact below. The team should confirm when deletion has been completed.

Need help?

For connection issues, data access/deletion requests, or privacy questions, please contact the Run for Impact 2026 Organizing Team (BTC).

Support contact: HCMC-HR@savills.com.vn

This application is an internal Savills campaign application and is not developed or sponsored by Strava.

About the Strava integration

The integration is used to connect an employee's Strava account to their Run for Impact experience. Access is subject to the permissions granted by the employee. Run for Impact does not require employees to share their Strava password.

For information about Strava's own account and privacy controls, visit Strava's settings and support pages.
